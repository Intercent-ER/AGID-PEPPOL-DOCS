= Tender reference (CIG)

To identify the call for tender or the lot the invoice relates to, use the 'OriginatorDocumentReference'. The identifier is, in most cases, the Procurement Procedure Identifier #("Codice Identificativo di Gara – CIG")#.

#The indication of the CIG code is mandatory in those contexts where it is required, and is necessary for the verification, reconciliation and payment approval processes of invoices.#

.UBL example of tender reference (CIG)
[source, xml, indent=0]
----
<cac:OriginatorDocumentReference>
    <cbc:ID>ppid-123</cbc:ID>
</cac:OriginatorDocumentReference>0
----

#To refer to a CIG code from invoice line, the information can be specified in *cac:DocumentReference* with document type code = 130, as in the following example:#

.UBL example of tender reference (CIG) from invoice lines
[source, xml, indent=0]
----
<cac:DocumentReference>
    <cbc:ID schemeID="AGB">90305884F7</cbc:ID>
    <cbc:DocumentTypeCode>130</cbc:DocumentTypeCode>
</cac:DocumentReference>
----
