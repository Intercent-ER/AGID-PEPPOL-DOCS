= #Reference to the main invoice# (extension)

In the case of invoices for ancillary operations, issued by parties that provide road transportation services for goods to benefit from exemptions regarding the registration and payment of VAT, it is possible to refer to the main invoice related to the transportation of goods in order to certify the ancillary operations.
