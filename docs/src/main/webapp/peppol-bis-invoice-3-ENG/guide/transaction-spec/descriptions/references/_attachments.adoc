= #Attachments#

The element used to store attachment information (AdditionalDocumentReference) can be repeated multiple times, allowing for multiple attachments.

Attachments can be used to provide additional information supporting the payment request represented by the invoice. Additional information may include attendance sheets, receipts, airline tickets, etc.

[NOTE]

====
The purpose of the attachment is *not* to transfer the PDF version of the invoice.
====

Attachments can be graphics and images. They may be sent as binary objects or as an external address pointing to the location where the object is stored (URI). Attachments sent as binary objects should be limited to the MIME types specified in the IANA code list.

It is recommended to send additional information included within the message format rather than as external addresses (URIs), since many companies have restricted access to external links.
