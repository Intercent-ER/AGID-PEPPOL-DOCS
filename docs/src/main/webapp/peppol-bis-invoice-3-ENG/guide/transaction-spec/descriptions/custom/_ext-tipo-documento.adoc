= #Document type (extension)#

In addition to the invoice type indicated in InvoiceTypeCode (e.g., 380 – commercial invoice), the document type provides a more specific classification of the invoice, such as deferred invoices, self-invoices, etc., in accordance with Italian regulations. 

Below is the link:pass:[${peppoldocs.root.url}/xml/ITA/peppol-bis-invoice-3/codelist/TipoDocumento%20FatturaPA.html][link] to the Italian codelist containing the Document type codes.

If the document type is not specified, it is understood to be a commercial invoice (TD01). 

.UBL example to specify the document type as a UBL extension
[source, xml, indent=0]
----
<ext:UBLExtension>
        <ext:ExtensionURI>urn:fdc:agid.gov.it:fatturapa:TipoDocumento</ext:ExtensionURI>
        <ext:ExtensionContent>
            <cbc:TypeCode>TD22</cbc:TypeCode>
        </ext:ExtensionContent>
</ext:UBLExtension>
----
