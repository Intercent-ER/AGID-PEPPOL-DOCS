= #Work in progress phase reference (WIP)#

To refer to the WIP phase, the information can be expressed as follows:

.UBL example for WIP phase reference
[source, xml, indent=0]
----
<cac:AdditionalDocumentReference>
    <cbc:ID schemeID="AOR">001</cbc:ID>
    <cbc:DocumentTypeCode>130</cbc:DocumentTypeCode>
</cac:AdditionalDocumentReference>
----

To refer to a WIP phase from invoice line, the information can be specified in *cac:DocumentReference* with document type code = 130, as in the following example:

.UBL example for the WIP phase reference from invoice lines 
[source, xml, indent=0]
----
<cac:DocumentReference>
    <cbc:ID schemeID="AOR">001</cbc:ID>
    <cbc:DocumentTypeCode>130</cbc:DocumentTypeCode>
</cac:DocumentReference>
----
