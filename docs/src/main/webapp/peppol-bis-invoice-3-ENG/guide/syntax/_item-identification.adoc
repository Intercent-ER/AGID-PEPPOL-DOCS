<1> 0160 is the ICD value for a GTIN identifier

#Within the Italian context, the management of the Drug Marketing Authorization Number for the medicinal products is carried out through the element *cac:SellersItemIdentification/cbc:ID* (BT-155 Item Seller's Identifier), in which the Drug Marketing Authorization Number is indicated, preceded by the string "AICFARMACO:".#

[NOTE]
This pertains to domestic CIUS (DC).

.UBL example of AIC identifier for medicinal products
[source, xml, indent=0]
----
<cac:SellersItemIdentification>
    <cbc:ID>AICFARMACO:025829211</cbc:ID> 
</cac:SellersItemIdentification>
----

#Within the Italian context, the management of the fuel type is carried out through *cac:SellersItemIdentification/cbc:ID* (BT-155 Item Seller's Identifier), in which the value from the reference table for energy products TA13 (published on the Italian Customs Agency website) is indicated, preceded by the string "CARB:".#

[NOTE]
This pertains to domestic CIUS (DC).

.UBL Example indicating the fuel type 
[source, xml, indent=0]
----
<cac:SellersItemIdentification>
    <cbc:ID>CARB:27101249</cbc:ID> 
</cac:SellersItemIdentification>
----
