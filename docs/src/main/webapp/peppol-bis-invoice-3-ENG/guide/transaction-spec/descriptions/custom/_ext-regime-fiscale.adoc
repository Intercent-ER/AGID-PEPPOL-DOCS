= #Fiscal regime (extension)#

The fiscal regime indicates the accounting or tax regime associated with the seller, and therefore the specific simplifications or benefits it is subject to.

Below is the link:pass:[${peppoldocs.root.url}/xml/ITA/peppol-bis-invoice-3/codelist/RegimeFiscale.html][link] to the Italian codelist containing the Fiscal Regime codes.

If the fiscal regime is not specified, it is understood to be the ordinary regime (RF01).

.UBL Example to specify the Fiscal Regime
[source, xml, indent=0]
----
<cac:AccountingSupplierParty>
    <cac:Party>
    ...
        <cac:PartyTaxScheme>
            <cbc:CompanyID>IT07643520567</cbc:CompanyID>
            <cbc:TaxLevelCode>RF19</cbc:TaxLevelCode>
            <cac:TaxScheme>
                <cbc:ID>VAT</cbc:ID>
            </cac:TaxScheme>
        </cac:PartyTaxScheme>
    ...
    </cac:Party>
</cac:AccountingSupplierParty>
----
