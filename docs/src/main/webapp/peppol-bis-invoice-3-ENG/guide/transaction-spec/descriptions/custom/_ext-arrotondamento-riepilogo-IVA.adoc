= #Taxable amount rounding in VAT summary# (Extension)

Any rounding adjustments needed to align taxable amounts in the VAT summary to the nearest euro cent can be provided as a UBL extension in the invoice header.

.UBL example to provide rounding of taxable amount in VAT Summary
[source, xml, indent=0]
----
<ext:UBLExtension>
    <ext:ExtensionURI>urn:fdc:agid.gov.it:fatturapa:RiepilogoIVA:Arrotondamento::1</ext:ExtensionURI>
    <ext:ExtensionContent>
        <cbc:Amount currencyID="EUR">0.5</cbc:Amount>
    </ext:ExtensionContent>
</ext:UBLExtension>
<ext:UBLExtension>
    <ext:ExtensionURI>urn:fdc:agid.gov.it:fatturapa:RiepilogoIVA:Arrotondamento::2</ext:ExtensionURI>
    <ext:ExtensionContent>
        <cbc:Amount currencyID="EUR">0.8</cbc:Amount>
    </ext:ExtensionContent>
</ext:UBLExtension>
----
